# CUSTOMER_DEVELOPMENT.md — Buyer Conversation Log

> **Rule:** 3 buyer conversations per week, every week. Non-negotiable. Skipped weeks get flagged in the next sprint review.
> **Format:** one entry per conversation. Brief. Honest. Quotes are gold — write them down verbatim while you remember.
> **Why this file exists:** the 57-session failure mode produced revenue-free progress because the founder built without talking to buyers. This file is the antidote.

---

## How to use this file

Every conversation gets logged. Bad conversations count. Calls that got rejected count. The discipline is *had the conversation*, not *got the answer you wanted*.

Each entry needs:
- **Date** — when the conversation happened
- **Who** — first name + locality (or pseudonym if they want privacy)
- **Stage** — *Searching / Decided on plot / Already bought / Broker / Lawyer / HFC / Other*
- **Format** — *Call / In-person / WhatsApp / In-app feedback*
- **Top 3 things they said** — verbatim where possible
- **What I'm going to do about it** — the action item, or "no action, just observation"

## Patterns I'm watching for (update as they emerge)

These are hypotheses to validate or kill through conversations:

1. **Trust gap at first contact** — buyers cite "never heard of this site" as the reason they don't pay. **Test:** does the free preview close the gap?
2. **Lawyer-vs-ClearDeed framing** — do buyers see this as competing with a lawyer or complementing one? **Test:** quote them back the "makes the lawyer's work cheaper and more targeted" framing and watch their reaction.
3. **Broker as gatekeeper vs blocker** — will brokers actually recommend ClearDeed, or will they actively dissuade? **Test:** ask 3 brokers directly. Two real conversations with brokers in PI 1.
4. **Price elasticity at ₹999** — would they pay ₹1,499? ₹1,999? **Test:** ask 10 buyers retrospectively after they've seen the report.
5. **Feature-they-cite vs feature-we-built** — buyers describing what they liked rarely matches what we thought was the value. **Test:** track which sections show up in feedback vs analytics.
